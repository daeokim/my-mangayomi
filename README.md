# my-mangayomi

개인용 Mangayomi 확장 저장소입니다.

## 저장소 주소

앱에서 More → Settings → Browse 로 이동한 뒤, 아래 주소를 각 칸에 입력합니다.

| 구분 | 입력할 칸 | 주소 |
|---|---|---|
| 만화 | Manga repo | `https://daeokim.github.io/my-mangayomi/index.json` |
| 영상 | Anime repo | `https://daeokim.github.io/my-mangayomi/anime_index.json` |

## Android APK 사용

이 저장소는 JS 확장과 목록을 배포하며 앱 APK 자체를 만드는 프로젝트가 아닙니다.
Mangayomi 공식 GitHub 정식 릴리스 APK를 설치하고 위의 만화·영상 저장소를 각각 등록합니다.
2026-10-14 확인 기준 공식 정식 버전은 `0.9.9`입니다.
휴대폰 내부 HLS 중계를 사용하려면 공식 앱 `0.9.9` 이상을 권장합니다.

- 공식 릴리스: https://github.com/kodjodevf/mangayomi/releases/tag/v0.9.9
- 업데이트 전에 앱에서 보관함과 설정을 백업합니다.
- 저장소 목록과 설치된 JS 확장은 앱 APK와 별도로 업데이트합니다.
- 티비룸·티비위키의 새 확장은 로컬 재생목록과 휴대폰 중계를 우선합니다.
- 실제 휴대폰 재생은 아직 미검증입니다. 사이트 통신과 플레이어 상태에 따라 외부 복구 재생이 필요할 수 있습니다.
- Aniyomi/Mihon의 APK 확장 저장소 형식은 이 저장소의 JS 목록과 다릅니다.
  다른 앱을 사용할 때는 해당 앱용 저장소와 확장을 설치해야 합니다.

## 휴대폰 HLS 중계 — 2026-10-14

티비룸 `0.1.28`, 티비위키 `0.1.14`에서 영상 재생 경로를 최적화했습니다.
소스 ID·보관함·수동 주소 설정은 유지합니다. 별도 개조 앱 APK는 필요하지 않습니다.

1. 공식 Mangayomi 앱을 `0.9.9` 이상으로 업데이트합니다.
2. 영상 확장 목록을 새로고침하고 티비룸·티비위키 확장을 업데이트합니다.
3. 각 소스 설정의 **영상 재생 경로 → 자동 (휴대폰 우선)** 을 사용합니다.
4. 회차를 다시 열고 **휴대폰 중계** 재생 옵션을 선택합니다.
   이전 앱이거나 내부 중계 생성에 실패하면 **직접 재생 (로컬 재생목록)** 으로 표시될 수 있습니다.
5. 문제가 있으면 재생 옵션의 **외부 빠른 재생 (복구)** 또는 **외부 호환 재생 (복구)** 를 선택합니다.
   소스 설정에서 **기존 외부 재생**을 선택하면 이전 경로만 사용합니다.

- 티비룸: 재생목록과 지원하는 AES-128 영상 키를 휴대폰에서 처리합니다.
  영상 조각 요청은 공식 앱의 내부 HLS 중계로 전달하며 원래 Referer·Origin·User-Agent를 유지합니다.
  이 경로는 외부 재생목록·키 처리 서버에 요청하지 않습니다.
- 티비위키: 사이트 직접 세션을 먼저 생성하고 실패 때만 기존 세션 서버를 사용합니다.
  확인된 키 조각 형식은 로컬에서 처리합니다. 다른 형식은 기존 서버의 키 변환을 사용하고
  **휴대폰 중계 (키 변환은 외부)** 로 표시합니다. 외부 의존성이 전부 제거된 것은 아닙니다.
- 완성된 단일 VOD 재생목록만 로컬에서 고정합니다. 라이브·마스터·키 교체 재생목록 등은
  기존 복구 경로를 유지합니다. 영상 다운로드도 기존 외부 경로를 사용할 수 있습니다.
- 티비룸 HTTP 재시도와 티비위키 세션 요청의 대기 시간을 줄였습니다.
  JS 타이머가 제공되는 앱에서는 재생 준비 요청에 별도 제한시간도 적용합니다.

검증: Node 회귀 검사, 암호화된 자체 제작 HLS 시험 영상의 FFmpeg 디코딩을 사용합니다.
시험 영상은 20프레임·영상 조각 4개이며 헤더가 틀리면 CDN 시험 서버가 403을 반환합니다.
내부 HTTP 시험 서버는 공식 앱의 중계 URL 계약을 모사합니다. Android/libmpv 실제 기기 검증과는 다릅니다.

## Aniyomi 선택 확장

Aniyomi용 만화 3개(11툰·블랙툰·굿툰), 영상 4개(DC 영화·드라마·예능·애니)를
포함한 별도 APK와 저장소를 추가했습니다. [설치·검증 안내](aniyomi/README.md)를 확인하세요.
DC 원본 APK의 소스 생성 부분을 수정한 개인용 구성입니다. 실제 기기 재생은 미검증이며,
DC 영상 4개는 티비룸 기반입니다. 기존 Mangayomi JS 저장소와는 별도입니다.

## 주소 업데이트 — 2026-10-13

티비위키를 53(0.1.11), 블랙툰을 424(0.1.17)로 변경했습니다. 자동 조회·저장된 주소가
티비위키 53 미만 또는 블랙툰 424 미만이면 현재 예비 주소를 사용합니다. 이전 주소 캐시는
새 키로 시작합니다. 수동으로 저장한 주소는 유지되므로 52·423을 직접 입력했다면
53·424로 수정하거나 입력란을 비워 자동 조회로 돌아갑니다. Aniyomi Daeo Manga도
블랙툰 기본 번호 424로 재빌드했습니다. Daeo Media는 티비룸 기반이므로 티비위키 변경 대상이 아닙니다.

## 주소가 바뀌었을 때

목록이 비어 있거나 접속이 되지 않을 때는 주소 변경 외에도 네트워크 오류,
사이트 구조 변경, 외부 서버 장애가 원인일 수 있습니다.

현재 확장은 앱에서 직접 지정한 주소를 우선합니다. 직접 지정한 값이 없으면
개인 공통 주소 목록 `domains.json`을 조회합니다. 다섯 소스 모두 조회한 주소를 캐시에 저장합니다.
목록 파일의 `baseUrl`은 자동 조회가 실패했을 때 사용하는 예비 주소입니다.
이때 저장된 주소가 있으면 그것을 먼저 사용합니다.
굿툰 007·티비위키 53으로 전환한 뒤에는 자동 조회가 이전 굿툰 006·티비위키 51을
돌려주어도 그 주소로 되돌아가지 않습니다. 티비위키 0.1.11은 이전 버전의 자동
주소 캐시를 새로 시작합니다. 직접 입력한 주소는 업데이트 후에도 우선합니다.

현재 주소를 직접 지정하려면 아래 순서로 진행합니다.

1. 브라우저에서 같은 사이트의 현재 주소를 확인합니다.
2. Mangayomi에서 설치된 확장의 설정을 열어 주소 입력 항목을 찾습니다.
   항목 이름에는 `주소 직접 지정` 또는 `도메인`이 포함되어 있습니다.
3. 현재 주소를 입력하고 목록을 새로고침합니다.
4. 자동 주소 조회로 돌아가려면 직접 입력한 값을 비웁니다.

저장소의 예비 주소를 바꾸려면 해당 목록 파일(`index.json` 또는
`anime_index.json`)의 `baseUrl`과 JS 파일 상단의 `baseUrl`, 생성자의
`fallbackBaseUrl`을 같은 주소로 맞춥니다. JS를 변경하면 목록 파일과 JS 상단의
`version`도 함께 올려야 설치된 확장에서 업데이트를 확인할 수 있습니다.
GitHub Pages 배포가 완료된 뒤 앱에서 저장소 목록과 확장 업데이트를 확인합니다.
사이트 주소를 바꿀 때 `sourceCodeUrl`과 앱에 등록한 저장소 주소는 유지합니다.

각 확장은 같은 사이트의 정해진 도메인 형식만 허용합니다. 다른 사이트 주소를
넣으면 거부되거나 목록 파싱이 실패합니다.

11toon과 굿툰은 잘못된 수동 주소를 입력하면 오류를 표시합니다. 자동 주소로
돌아가려면 입력란을 비우세요. 11toon은 `https://www.11toon144.com` 같은
`11toon숫자.com` 형식도 허용하지만, 주소가 허용된다는 것이 실제 접속을
보장하지는 않습니다.

## 티비위키 웹뷰는 열리는데 앱 목록이 없을 때

웹뷰는 브라우저 엔진으로 페이지를 표시하지만 확장은 별도의 HTTP 요청으로
받은 HTML에서 작품을 추출합니다. 따라서 웹뷰 접속만으로 목록 요청의 주소,
응답 내용, 접속 확인 상태와 HTML 구조가 정상임을 확인할 수는 없습니다.

- 예전 코드는 중앙 조회가 실패하면 목록 파일보다 저장된 주소를 우선했고,
  생성자의 예비 주소도 목록의 52와 달리 51이었습니다.
- 0.1.11은 예비 주소를 53에 맞추고 이전 자동 주소 캐시를 초기화합니다.
- `CHALLENGE`: 목록 HTML 대신 접속 확인 페이지를 받았습니다. 이전에는 HTTP
  200 응답이면 정상으로 처리해 작품이 없는 화면으로 이어질 수 있었습니다.
- `NO_CARDS`: 첫 페이지에서 작품을 추출하지 못했습니다. 요청 주소를 오류에
  표시합니다. 주소가 맞으면 응답 내용 또는 사이트 구조를 추가 확인해야 합니다.
  사이트가 명시한 빈 검색 결과와 두 번째 이후의 빈 페이지는 정상으로 허용합니다.

앱의 영상 확장 목록을 새로고침하고 티비위키를 업데이트한 다음,
`티비위키 주소 직접 지정`에 웹뷰에서 실제로 열린 최종 주소를 입력해 비교하세요.
수동 주소를 비우면 자동 조회로 돌아갑니다. 휴대폰 응답을 재현하지 않았으므로
쿠키 문제나 사이트 구조 변경을 이번 증상의 확정 원인으로 단정하지 않습니다.

## 만화 뷰어가 비어 있을 때

- `RESET`: 요청 중 연결이 끊겼습니다. 웹뷰에서 같은 회차를 열고 Wi-Fi와
  모바일 데이터를 비교하세요. 코드 수정만으로 네트워크 문제를 해결할 수는 없습니다.
- `CHALLENGE`: 굿툰 요청이 접속 확인 페이지를 받았습니다. 웹뷰에서 같은
  회차를 확인하세요. 웹뷰의 쿠키가 확장 요청에도 적용되는지는 별도 확인이 필요합니다.
- `NO_IMAGES`: 굿툰이 받은 페이지에서 이미지 주소를 추출하지 못했습니다.
  사이트 구조 변경이나 로그인·접속 확인 페이지일 수 있습니다.
- 이미지 주소를 추출했어도 이미지 서버 연결이나 요청 헤더 문제로 표시가
  실패할 수 있습니다. 오류 화면과 해당 회차 주소를 함께 확인해야 합니다.

Rabbit 외부 인증은 별도 서버가 필요한 선택 기능입니다. 빈 뷰어만으로 서버가
필요하다고 단정하거나 설정을 켜지 마세요. 이번 수정은 1.1.1.1/WARP 없이
항상 접속되게 하는 기능이 아닙니다.

## 외부 서버 의존성

JS 파일은 이 저장소에서 받지만, 다음 기능은 원저자의 서버를 사용합니다.

- 자동 주소 후보 수집: `wankyo83.github.io/tokki-traffic-light/domains.json` (개인 목록 갱신 시 참고하며 검증 후 채택)
- 아이콘과 목록 카드: 원본 만화·미디어·소설 저장소
- 티비위키: 직접 세션 실패 때의 세션 복구와 미지원 영상 키 형식 변환
- 티비룸: 외부 복구 재생과 지원하지 않는 재생목록 형식 처리

영상 처리 서버는 `dc-toki-mangayomi-media.pages.dev`입니다. 이 서버가 중단되면
저장소 파일을 정상적으로 받아도 일부 영상이 재생되지 않을 수 있습니다.
해당 서버는 정적 파일만 복사하는 것으로 대체할 수 없습니다.

## 변경 내용과 검사

- 영상 확장이 외부 주소 조회에 실패했을 때 목록의 예비 주소를 사용하도록 수정했습니다.
- 티비룸·티비위키·굿툰의 코드 내 예비 주소를 현재 목록과 맞췄습니다.
- 만화 확장의 로컬 개발용 아이콘 주소를 원본 공개 아이콘 주소로 수정했습니다.
- 확장 버전과 목록의 버전을 함께 올렸습니다.
- 11toon의 이미지 검사와 최종 이미지 주소에 현재 회차의 사이트 주소를 사용합니다.
  다른 이미지 CDN 주소는 유지합니다.
- 굿툰의 접속 확인 응답과 이미지 추출 실패를 구분하고, 잘못된 수동 주소를 안내합니다.
- 굿툰 외부 인증 결과에 이미지 요청 헤더가 없으면 명확한 오류를 표시합니다.
- 11toon의 회차 목록 영역이 없으면 문서 전체에서 회차 버튼을 찾습니다.
- 블랙툰의 목록·인기 순위 데이터는 30분, 사이트 설정은 24시간 후 다시 조회합니다.
  같은 데이터의 동시 요청은 공유하며, 이전 도메인의 늦은 응답이 현재 데이터 캐시를
  덮어쓰지 않도록 했습니다. 만료된 목록은 먼저 표시하고 백그라운드에서 갱신하므로
  갱신 완료 후 다시 새로고침하면 최신 결과를 볼 수 있습니다.
- 티비룸의 상대 영상 주소를 플레이어 기준으로 변환합니다. `../` 경로와
  `//`로 시작하는 CDN 주소도 처리하며 기존 요청 헤더는 유지합니다.

Node.js가 설치된 환경에서 다음 명령으로 회귀 테스트를 실행합니다.

```sh
node --test tests/extensions.test.cjs
```

테스트는 주소 선택, 캐시, 메타데이터, 파일 연결을 네트워크 요청 없이 검사합니다.
만화 뷰어의 주소 처리와 오류 분류도 모의 응답으로 검사합니다.
회차 영역 누락, 블랙툰 캐시 만료·동시 요청·도메인 변경, 티비룸 영상 주소도 검사합니다.
실제 Mangayomi 목록 표시와 이미지·영상 재생은 앱에서 별도로 확인해야 합니다.

## 참고 사항

- 만화 소스 세 개는 `isNsfw: true` 입니다. 앱에서 NSFW 소스 표시를
  꺼두면 목록에 나타나지 않습니다.
- `appMinVerReq` 보다 앱 버전이 낮으면 확장이 로드되지 않습니다.
  현재 기준 최소 **0.9.3** 이상을 권장합니다.
- index 파일은 반드시 대괄호 `[ ]` 로 감싼 배열이어야 합니다.
